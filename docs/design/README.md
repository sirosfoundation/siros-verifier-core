# Design history and developer material

This directory preserves design notes, spike findings, and developer-only examples. It is not user or integrator documentation, and nothing here is a supported configuration contract.

- `FINDINGS.md`: historical interoperability and security findings. Later addenda may supersede earlier “not done” entries; consult current source and tests before treating an entry as current behavior.
- `go-trust-issue.md`: design proposals for trust lifecycle improvements, not shipped functionality.
- `examples/`: Rust developer tools for benchmarks, independent vector generation, and live-PDP fixtures.

For supported integration guidance, start at [`docs/README.md`](../README.md).
